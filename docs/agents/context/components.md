# Component Context

## Feature Components (`src/components`)

- **Adaptive** (`src/components/Adaptive`): Handles responsive layouts for different screen sizes.
- **ButtonWar** (`src/components/ButtonWar`): A specific interactive component.
- **Contacts** (`src/components/Contacts`): Contact information section.
- **Introduce** (`src/components/Introduce`): Introduction section.
- **Welcome** (`src/components/Welcome`): Welcome/Hero section.
- **WindowsClone** (`src/components/WindowsClone`): A complex component simulating a Windows desktop environment.

## Shared Components (`src/shared`)

- **Button** (`src/shared/Button`): Reusable button component.
- **InWorkMobile** (`src/shared/InWorkMobile`): Mobile-specific component.
- **Link** (`src/shared/Link`): Reusable link component.
- **Paragraph** (`src/shared/Paragraph`): Reusable paragraph component.

## Widgets (`src/widgets`)

- **Header** (`src/widgets/Header`): Top navigation/header component.
