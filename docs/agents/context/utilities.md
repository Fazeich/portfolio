# Utility Context

## Core Utilities and Libs (`src/lib`)

- **api.ts** (`src/lib/api.ts`): API interaction logic.
- **constants.ts** (`src/lib/constants.ts`): Application-wide constants.
- **endpoints.ts** (`src/lib/endpoints.ts`): API endpoint definitions.
- **router.tsx** (`src/lib/router.tsx`): Routing logic.
- **styles.ts** (`src/lib/styles.ts`): Global styles or styling utilities.
- **theme.ts** (`src/lib/theme.ts`): Theme configuration.
- **types.ts** (`src/lib/types.ts`): Global TypeScript types.

## State Management (Stores) (`src/stores`)

- **buttonWar** (`src/stores/buttonWar`): Effector store for ButtonWar feature.
- **main** (`src/stores/main`): Main application state store.
- **windowsClone** (`src/stores/windowsClone`): Effector store for WindowsClone feature.
